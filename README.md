# Multi-Source Web Scraping & Data Consolidation

## 1. Project Overview

This project implements the Realisieren Technologies Python web scraping assignment.

The pipeline collects public data from:

1. **Books to Scrape** — https://books.toscrape.com/
2. **Quotes to Scrape** — https://quotes.toscrape.com/

The workflow is:

```text
Scrape -> Clean -> Validate -> Deduplicate -> Consolidate -> Save
```

The assignment requires dynamic pagination, common data modeling, cleaning, validation, duplicate detection, error handling, logging, tests, and reproducible documentation.

## 2. Why Requests + BeautifulSoup?

Both target websites are server-rendered HTML practice sites. Requests is sufficient for downloading their HTML and BeautifulSoup provides straightforward CSS-selector based parsing. Selenium or Playwright would add browser overhead without being necessary for these pages.

## 7. Source Exploration and Selectors

### Books to Scrape

| Field | Selector / method |
|---|---|
| One record | `article.product_pod` |
| Title | `h3 > a`, preferably the `title` attribute |
| Price | `p.price_color` |
| Rating | classes on `p.star-rating` |
| Link | `h3 > a[href]` |
| Next page | `li.next > a` |

### Quotes to Scrape

| Field | Selector / method |
|---|---|
| One record | `div.quote` |
| Quote text | `span.text` |
| Author | `small.author` |
| Tags | `a.tag` |
| Author link | `a[href^="/author/"]` |
| Next page | `li.next > a` |

These selectors are kept inside the source-specific scraper modules.

## 8. Pagination

The implementation does **not** hard-code the number of pages.

Each scraper:

1. Starts from the site's home page.
2. Downloads the current page.
3. Parses all records.
4. Finds `li.next > a`.
5. Uses `urljoin()` to convert the relative link to an absolute URL.
6. Repeats until there is no next link.

Therefore, if the number of pages changes, the scraper does not need a page-count change.

## 9. Common Data Model

Every final CSV row uses this schema:

| Column | Books | Quotes |
|---|---|---|
| `source` | `Books to Scrape` | `Quotes to Scrape` |
| `source_url` | Book detail URL | Page URL where quote appeared |
| `name_or_title` | Book title | Quote text |
| `category` | Empty | Empty |
| `price` | Numeric price | Empty |
| `rating` | Integer 1–5 | Empty |
| `author` | Empty | Author name |
| `tags` | Empty | Lowercase, sorted, semicolon-separated tags |
| `description` | Empty | Empty |
| `scraped_at` | UTC timestamp | UTC timestamp |

### Category and description decision

The Books listing page does not contain category or description. The assignment reference explicitly allows either visiting every detail page or leaving these fields empty and documenting the limitation.

This implementation leaves them empty. It does **not** invent values and avoids approximately 1,000 additional detail-page requests.

## 10. Cleaning

Cleaning is isolated in `processing/cleaning.py`.

### Text

- Converts non-breaking spaces to normal spaces.
- Collapses repeated whitespace.
- Converts empty values to `None`.

### Quote text

Removes the surrounding curly quotation marks when present.

### Price

Converts values such as:

```text
£51.77
```

to:

```text
51.77
```

### Rating

Converts word ratings:

```text
One -> 1
Two -> 2
Three -> 3
Four -> 4
Five -> 5
```

### Tags

Tags are normalized to lowercase, deduplicated, sorted, and joined with `;`.

Example:

```text
Technology;life
```

## 11. Validation

`processing/validation.py` returns a list of problem codes.

Checks include:

- Known source.
- Non-empty `name_or_title`.
- HTTP/HTTPS source URL.
- Numeric non-negative price when present.
- Rating from 1 through 5 when present.
- Author required for quote records.

Invalid records are rejected without stopping the complete pipeline. Rejection reasons are counted in `summary_report.json` and written to the log.

## 12. Duplicate Detection

Duplicate detection is implemented in `processing/deduplication.py`.

### Books

Fingerprint:

```text
source + normalized title
```

### Quotes

Fingerprint:

```text
source + normalized author + first 50 characters of normalized quote
```

Normalization:

1. Lowercase.
2. Remove punctuation.
3. Collapse whitespace.
4. Hash the resulting key with SHA-256.

For example, these book titles are treated as duplicates:

```text
Example Book Title
 Example Book Title
EXAMPLE BOOK TITLE
```

Duplicates are **removed** from the final CSV. The number removed is recorded in the summary.

## 13. Error Handling

The shared HTTP helper:

- Uses a `requests.Session`.
- Sends a descriptive User-Agent.
- Uses a timeout.
- Retries temporary failures such as 429, 500, 502, 503 and 504.
- Uses exponential backoff.
- Logs final request failures.

The program also:

- Handles missing HTML elements.
- Skips malformed individual records.
- Stops only the affected source if a page cannot be fetched.
- Continues to the other source.
- Logs rejected records and parsing errors.

A 0.5-second delay is used between requests as required by the reference.

## 18. Assumptions

- The two specified public practice sites remain available and retain their expected HTML structure.
- The source page URL is used for quote records rather than the author page URL.
- Category and description are left empty because they are not available on the book listing page.
- Missing optional source-specific fields are represented as empty CSV cells.
- Duplicate records are removed rather than flagged.
- Only public pages are accessed.

## 19. Known Limitations

- Website HTML changes could require selector updates.
- Category and description are not collected from book detail pages.
- A source is stopped after a page fails after its configured retries; the other source continues.
- The scraper is designed for this assignment rather than a production-scale distributed crawling system.
- No authentication, CAPTCHA bypass, or access-control bypass is implemented.
